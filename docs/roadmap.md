# Roadmap

## Phase 0

- finalize system boundaries
- define domain contracts
- define the first predictive target

## Phase 1

- ingest historical daily data
- build point-in-time feature pipeline
- implement baseline backtest accounting

## Phase 2

- train one baseline alpha model
- add white-box portfolio sizing
- add basic risk veto rules

## Phase 3

- simulate execution and transaction costs
- compare model variants under the same pipeline
- add experiment tracking and model review notes

## Phase 4

- run paper trading
- add monitoring and alerting
- integrate one real broker after paper stability
