# Memo: Non-Price 因子设计需求

## 1. 这份 memo 的目的

这份 memo 不是要 Non-Price 线程去设计一批新的通用 alpha 因子，然后和我们现有的 price alpha 直接拼接。

这份 memo 的目标更具体：

- 帮我们刻画一个更底层的“状态参数”；
- 用这个状态参数去判断，我们当前的 long / short selector 什么时候会失灵，甚至发生倒置；
- 因此，Non-Price 因子首先应该服务于 **selector validity / regime diagnosis**，其次才是 stock-level alpha。

一句话说，我们要的不是“再来一些能预测收益的因子”，而是：

**再来一些能帮助我们判断“当前这套选股逻辑还是否可信”的因子。**

## 2. 我们现在对“参数”的理解

### 2.1 经济上的核心解释

我们现在看到的偶发性失灵窗口，本质上不是随机噪声，而是：

**价格形成机制发生了切换。**

平时主导价格的是：

- 错价修复；
- 分散信息；
- 常规套利资本；
- 愿意逢低买、逢高卖的吸收型资金。

少数坏窗口里，主导价格的变成了：

- 被迫交易；
- 风险预算收缩；
- 拥挤交易；
- 趋势资金追逐；
- 业绩/预期连续上修或下修引发的正反馈。

当后一类力量占上风时，我们的 selector 就容易失灵：

- long 端会把“还没跌完的 loser”误判为“该反弹的超跌股”；
- short 端会把“基本面还在变好的强势 winner”误判为“该回落的过热股”。

### 2.2 用一个潜在状态参数来表达

我们可以把它抽象成两个潜在状态参数，而不是一个万能参数：

- `Phi_long,t`
- `Phi_short,t`

它们的经济含义可以理解为：

`Phi_long,t ≈ 持续卖压 / 均值回归吸收能力`

`Phi_short,t ≈ 持续上冲或 squeeze 压力 / 均值回归吸收能力`

解释如下：

- 当 `Phi_long,t` 高时，说明 long 候选里的下跌更像“被持续卖压主导”，而不是“错杀后等待修复”。
- 当 `Phi_short,t` 高时，说明 short 候选里的上涨更像“基本面改善 + 资金追逐 + squeeze”，而不是“过热后等待回落”。

因此：

- `Phi_long,t` 高 -> long reversal 更容易倒置；
- `Phi_short,t` 高 -> short mean reversion / shorting winner 更容易倒置。

### 2.3 为什么 price-only 不够

price-only 能告诉我们：

- 谁跌了很多；
- 谁涨了很多；
- 谁趋势很强；
- 谁结构性很弱。

但它很难回答下面两个关键问题：

1. 一只跌很多的股票，是“被错杀”，还是“基本面真的在恶化”？
2. 一只涨很多的股票，是“过热拥挤”，还是“基本面真的在持续改善”？

也就是说，price-only 更擅长看“形状”，不擅长看“原因”。

而我们现在最缺的，恰恰是“原因”。

## 3. Non-Price 因子应该解决什么问题

Non-Price 因子最重要的任务，不是提高全样本 IC，而是帮助我们做下面两类区分。

### 3.1 Long 侧：区分两类 loser

我们需要区分：

- **可反弹的 oversold loser**
- **不该抄底的 distress / structural loser**

也就是区分：

- 短期被错杀；
- 还是基本面、融资条件、行业位置、经营预期都在恶化。

### 3.2 Short 侧：区分两类 winner

我们需要区分：

- **可以做空的 overextended / crowded winner**
- **不该过早做空的 genuine improver**

也就是区分：

- 纯情绪和拥挤驱动的上涨；
- 还是盈利、预期、经营质量、资本市场支持都在改善的上涨。

## 4. 我们希望 Non-Price 因子具备什么特征

### 4.1 必须 point-in-time 且时点可用

- 因子必须能明确回答：在 `t` 日收盘后、或 `t+1` 日开盘前，是否真实可得；
- 不能用未来修订后的数据；
- 不能隐含未来财报、未来分析师修订、未来事件结果。

### 4.2 必须尽量高覆盖

我们做的是美股高流动性 top1000 / top1500 风格的策略，所以我们更偏好：

- 覆盖面广；
- 缺失率低；
- 不只覆盖小部分名字。

### 4.3 必须能提供“原因信息”

优先要那些告诉我们：

- 为什么跌；
- 为什么涨；
- 是否有真实基本面支撑；
- 是否存在融资/信用/预期压力；
- 是否存在拥挤和 squeeze 风险。

### 4.4 必须能 stock-level 和 basket-level 两用

理想的因子不只可以拿来 veto 某一只股票，还应能聚合成：

- long candidate basket 的风险温度；
- short candidate basket 的风险温度。

也就是它既能做：

- stock-level veto / overlay
- state index / activation signal

### 4.5 不要只是 price 的另一个变形

我们不希望 Non-Price 线程交回来的是：

- 换个窗口的 momentum；
- 换个标准化方式的 reversal；
- 本质仍然只是价格和成交量变换。

因为这不能有效补足我们现在的盲区。

## 5. 我们最需要的因子家族

下面按优先级列出我们最想要的 Non-Price 因子方向。

### 5.1 P0：Long-side 最优先

这些因子要帮助我们识别：**哪些跌很多的股票，实际上不该买。**

#### A. 分析师预期下修 / 上修因子

目标：

- 区分“纯价格超跌”与“盈利预期正在被系统性下修”。

理想形式：

- 近 `20/60` 交易日 EPS / revenue / EBITDA 预期净下修强度；
- 下修广度；
- 预期修订速度；
- 行业内相对修订强弱。

为什么重要：

- 如果 loser 同时伴随明显的预期下修，它更像 structural loser，而不是超跌反弹候选。

#### B. 财报 / 指引恶化因子

目标：

- 捕捉“价格下跌背后有真实信息冲击”的情况。

理想形式：

- earnings miss 强度；
- guidance cut；
- 负面业绩漂移；
- 财报后负面修订持续性。

为什么重要：

- 这种股票的下跌更可能是信息重定价，而不是错杀。

#### C. 融资压力 / 资产负债表脆弱度

目标：

- 识别“看起来超跌，但其实融资链条脆弱”的股票。

理想形式：

- 杠杆压力；
- 利息负担；
- 短债压力；
- 现金流紧张；
- 再融资需求；
- 流动性脆弱度。

为什么重要：

- risk-off 窗口中，这类股票容易出现持续卖压，long reversal 很容易接飞刀。

#### D. Insider 卖压 / 管理层行为因子

目标：

- 捕捉内部人是否也在强化负面判断。

理想形式：

- `insider_sell_pressure_score` 这一类因子的增强版；
- 净 insider sell；
- 卖出广度；
- 行业内相对 insider pressure。

为什么重要：

- 对 long 侧而言，内部人显著卖出通常会降低“错杀反弹”的可信度。

#### E. 行业基本面恶化广度

目标：

- 不只看个股，而是看所在行业是否处于系统性恶化中。

理想形式：

- 行业内预期下修广度；
- 行业内负面财报广度；
- 行业内利润率/需求走弱 proxy。

为什么重要：

- 如果整个行业都在恶化，则个股的“超跌”更可能是行业去风险的一部分，而不是个股错杀。

### 5.2 P0：Short-side 最优先

这些因子要帮助我们识别：**哪些涨很多的股票，实际上不该急着空。**

#### F. 分析师预期持续上修因子

目标：

- 识别“价格上涨是有基本面支撑的”winner。

理想形式：

- EPS / revenue / EBITDA 预期净上修；
- 上修广度；
- 上修持续时间；
- 行业内相对上修强弱。

为什么重要：

- 如果 winner 仍在持续获得预期支持，就更容易继续涨，而不是回落。

#### G. 财报 / 指引改善与 PEAD 支撑

目标：

- 区分“纯情绪上涨”与“财报驱动的持续上行”。

理想形式：

- earnings beat；
- guidance raise；
- 正面财报后的持续漂移；
- 事件新鲜度。

为什么重要：

- 这类 winner 不应被简单视作过热股。

#### H. Insider 买入 / 低卖压

目标：

- 判断管理层是否支持当前上涨逻辑。

理想形式：

- insider buy；
- 低 insider sell；
- 与历史和行业相比的异常程度。

为什么重要：

- 对 short 侧而言，这类名字更像 genuine improver，而不是可短的情绪票。

#### I. Borrow / Short Interest / Squeeze 风险

目标：

- 识别“技术上就不适合做空”的票。

理想形式：

- short interest；
- days-to-cover；
- borrow fee；
- borrow availability；
- squeeze proxy。

为什么重要：

- 这不是基本面因子，但对 short 侧的有效性极其关键。

#### J. 机构/资金积累与拥挤质量

目标：

- 区分“脆弱拥挤”与“有增量买盘支持的强势股”。

理想形式：

- 持仓增加；
- 资金持续流入；
- ownership 结构变化；
- ETF / 指数 / thematic flow 支持。

为什么重要：

- 某些 winner 看似拥挤，实际上仍有稳定买盘来源，过早做空容易被拖死。

### 5.3 P1：Long / Short 共用的辅助因子

#### K. 预期分歧 / 不确定性

目标：

- 判断市场对公司基本面是否高度分歧。

理想形式：

- 分析师预期离散度；
- 修订分歧；
- 盈利不确定性 proxy。

作用：

- 高分歧下，价格更容易出现强 continuation，而不是稳定均值回归。

#### L. 事件新鲜度

目标：

- 区分“旧消息的价格延续”与“新信息刚刚进入市场”。

理想形式：

- 距离财报/指引/重大事件的天数；
- 事件后信号衰减路径。

作用：

- 很多 reversal / shorting 失灵，发生在信息冲击还很新鲜的阶段。

#### M. 行业层面的拥挤 / 去风险温度

目标：

- 让状态判断不只停留在个股。

理想形式：

- 行业资金净流入/流出；
- 行业基本面修订广度；
- 行业风险偏好 proxy。

作用：

- 我们很多坏窗口本来就具有明显行业集中。

## 6. 我们不希望 Non-Price 线程交付什么

### 6.1 不优先要 generic slow factor

例如：

- 一般性的 value；
- 慢速 quality；
- 长周期 size；
- 宽泛的 defensive 风格。

这些当然有价值，但它们未必直接帮助我们识别 selector 倒置窗口。

### 6.2 不优先要黑盒大杂烩

我们现在不需要：

- 一个 50 个原子字段拼成、但解释不清的总分；
- 一个训练集上很强、但说不清机制的复杂模型。

我们更希望：

- 少量高解释力原子因子；
- 再由我们自己在主线程决定如何组合。

### 6.3 不优先要 price 的重复表达

如果一个“non-price”因子本质上仍然只是：

- 价格变换；
- 成交量变换；
- 波动率变换；

那它对我们当前问题的边际价值大概率有限。

## 7. 建议 Non-Price 线程的交付格式

每个候选因子建议按下面模板交付：

- `factor_name`
- `economic_mechanism`
- `update_frequency`
- `point_in_time_availability`
- `coverage_on_top1000`
- `expected_help_on_phi_long`
- `expected_help_on_phi_short`
- `stock_level_use`
- `basket_level_use`
- `known_failure_modes`

额外希望有的诊断：

- 缺失率；
- 极值分布；
- 行业内稳定性；
- 与已有 price 因子的重合度；
- 触发的典型股票案例。

## 8. 我们希望如何使用这些因子

请注意，我们短期内不打算把这些因子直接塞进主 alpha 模型里。

更合理的接入顺序是：

### 第一阶段：culprit attribution

先看这些因子能否解释我们已知的坏窗口：

- long-side：
  - `2015-06 ~ 2015-08`
  - `2016-01 ~ 2016-02`
  - `2019-05`
  - `2019-08`
- short-side：
  - `2017-03 ~ 2017-05`
  - `2018-08 ~ 2018-09`
  - `2019-05`

如果一个因子连这些坏窗口里的 culprit 名字都解释不了，它就很难对我们的“参数”真正有贡献。

### 第二阶段：state diagnosis

再看这个因子能否在 candidate basket 层面聚合成：

- long fragility index；
- short continuation / squeeze index。

也就是它能否帮助构建：

- `Phi_long,t`
- `Phi_short,t`

### 第三阶段：simple veto / overlay

最后才是非常克制地接入策略：

- veto 某些最危险的 long loser；
- veto 某些最不适合空的 short winner；
- 或作为 state-dependent activation 的输入。

## 9. 我们最看重的，不是“单因子 IC”，而是“对参数的贡献”

请 Non-Price 线程不要只用普通 alpha 口径评估这些因子。

我们更看重的是：

1. 它是否帮助解释已知失灵窗口；
2. 它是否能区分 oversold vs distress；
3. 它是否能区分 crowded winner vs genuine improver；
4. 它是否能在 basket 层面稳定聚合；
5. 它是否能以较低自由度接入当前白盒 state framework。

换句话说：

**我们要的不是“这个因子自己能赚多少钱”，而是“这个因子能否帮我们更准确地知道，什么时候原有 selector 不该被相信”。**

## 10. 对 Non-Price 线程的明确请求

请优先围绕下面两个目标设计因子：

### 目标 A：提升 `Phi_long,t` 的可观测性

帮助我们识别：

- 看起来跌多了；
- 但其实是预期恶化、融资脆弱、行业去风险、内部人卖出；
- 因而 **不该被当作 long reversal 候选** 的股票。

### 目标 B：提升 `Phi_short,t` 的可观测性

帮助我们识别：

- 看起来涨多了；
- 但其实是预期上修、财报改善、资金持续支持、squeeze 风险高；
- 因而 **不该被过早做空** 的股票。

如果只能先做一小批，请优先交付这几类：

- 分析师预期修订；
- 财报 / 指引恶化与改善；
- insider 行为；
- 融资 / 资产负债表脆弱度；
- borrow / short interest / squeeze proxy；
- 行业层面的基本面恶化或改善广度。

这几类因子最有希望真正增强我们对 `Phi_long,t` / `Phi_short,t` 的观测能力，而不是仅仅再给我们一组新的价格替代品。
